### **Linear Equation Solve (Questions 1-35)**

1. Write a function to solve a system of 2 linear equations in 2 variables (2x2 system) using the substitution method.
2. Write a function to solve a 2x2 system of linear equations using the elimination method.
3. Write a function to solve a 2x2 system using Cramer's rule (determinants).
4. Write a function to solve a 3x3 system using Cramer's rule.
5. Write a function to find the determinant of a 2x2 matrix.
6. Write a function to find the determinant of a 3x3 matrix using the rule of Sarrus.
7. Write a function to find the determinant of a 3x3 matrix using cofactor expansion.
8. Write a function to find the inverse of a 2x2 matrix using the determinant and adjugate.
9. Write a function to solve a 2x2 system by finding the inverse matrix and multiplying.
10. Write a function to convert a system of linear equations into an augmented matrix.
11. Write a function to perform forward elimination on an augmented matrix to get an upper triangular form.
12. Write a function to perform back substitution on an upper triangular augmented matrix.
13. Write a function to implement Gaussian elimination for a 3x3 system.
14. Write a function to implement Gaussian elimination for an nxn system (n <= 5).
15. Write a function to check if a 2x2 system has a unique solution, no solution, or infinitely many solutions.
16. Write a function to check if a 3x3 system has a unique solution (by checking determinant).
17. Write a function to find the rank of a 2x2 matrix.
18. Write a function to find the rank of a 3x3 matrix by converting to row echelon form.
19. Write a function to find the rank of an augmented matrix for a 3x3 system.
20. Write a function to detect inconsistency in an augmented matrix.
21. Write a function to find the solution of a 2x2 system where one equation is a multiple of the other (infinite solutions case).
22. Write a function to solve a system of 3 equations where one is a linear combination of the others.
23. Write a function to implement the Gauss-Jordan elimination method for a 3x3 system.
24. Write a function to reduce a matrix to reduced row echelon form (for 3x3).
25. Write a function to solve a system of 4 equations in 4 variables using Gaussian elimination (without `solve`).
26. Write a function that takes coefficients matrix A and vector b, and returns solution x for Ax = b for 2x2, using matrix inverse.
27. Write a function to compute the adjugate (adjoint) of a 3x3 matrix.
28. Write a function to find the inverse of a 3x3 matrix using the adjugate method.
29. Write a function to solve a 3x3 system using the matrix inverse method.
30. Write a function to find the trace of a square matrix (2x2, 3x3).
31. Write a function to check if a square matrix is singular (determinant = 0).
32. Write a function to find a particular solution of a system when there are infinitely many solutions (choose one free variable arbitrarily).
33. Write a function to solve an upper triangular system without using back substitution formula directly but using iterative loops.
34. Write a function to solve a lower triangular system.
35. Write a function to solve a diagonal system of equations.

These questions progress from basic arithmetic operations to implementing fundamental linear algebra algorithms, all without relying on R's built-in linear algebra functions (except for basic arithmetic). They cover the core concepts of solving linear equations, matrix manipulation, and vector operations.
